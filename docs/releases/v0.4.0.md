## rdpio 0.4.0

Copied files move at the network's full speed, and a laptop host lasts longer
on battery.

- **Fast file copies.** On the LAN, copies run over TCP connections of their
  own, no longer held to the video stream's rate. A paste starts right away
  and fills in as the files arrive. Between two Wi-Fi PCs, 400 MB took about
  11 s.
- **Copying files from the host works as that user**, including files only
  that user can read.
- **Longer battery on a laptop host.** On battery, the host can stream from
  the integrated GPU so the discrete one powers off, and it lets go of the GPU
  10 s into a paused stream. An idle desktop stays quieter too. Host GPU in
  the launcher, or `battigpu=0`, keeps the fastest GPU.
- **A stream window buried under others pauses the stream.**
- **Steadier picture.** The link is timed with probe trains, a LAN stream
  keeps a quality floor, and scrolled text sharpens in a few big passes.
- **Auto resolution on Windows**, and the burst-tolerant backlog, as on Android.
- **A host updates itself sooner.** A client on a newer rdpio gets the host
  updated after the stream, instead of up to 6 hours later.
