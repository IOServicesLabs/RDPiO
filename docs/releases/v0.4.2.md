## rdpio 0.4.2

The virtual display heals itself, office streams take in what the network
gives them, and the launcher keeps one place for each thing.

- **The virtual display comes back by itself.** After a GPU reset or a
  graphics driver update Windows could leave rdpio Display stopped (Code 43),
  and the host kept streaming its own monitor until a reboot. The host now
  checks the driver before every connect, restarts a stopped one, and holds it
  open only while a virtual monitor exists. If the monitor goes away
  mid-stream, the client reconnects onto a fresh one instead of the session
  ending. This PC shows why the display isn't running, with a Repair button.
- **A sturdier display driver.** The driver no longer waits without limit
  inside Windows' callbacks, which is what got it stopped, and keeps a short
  crash record the host logs. It ships separately: reinstall it from
  `drivers/rdpio-display` to get it.
- **Office mode takes the full stream.** The client no longer naps between
  packets while more are waiting, which held office streams near 5 Mbit/s.
- **The host knows which frame you have.** The client reports the newest
  complete frame, so loss is judged exactly: fewer needless slowdowns after a
  keyframe and faster repair when the last packets of a frame are lost. Older
  peers keep the previous behaviour.
- **Faster back from a pause and quicker starts.** On mains the GPU device
  stays ready while the window is minimised, mode changes and resizes no
  longer wait first, and stream set-up overlaps sign-in.
- **Truer timing.** Frames from the virtual display carry the time they were
  captured, the GPU clock is raised again as soon as you give input, and Auto
  resolution no longer halves the picture on a quiet LAN.
- **RDP.** A mouse move can no longer swallow a click, release or wheel step;
  remote sound plays through WASAPI with a short jitter buffer
  (`RDPIO_RDPSND=waveout` for the old path); an automatic reconnect keeps the
  window responsive and says what it is doing.
- **One place for each thing in the launcher.** One find-or-connect box, one
  connection menu, Updates only in Settings, one display card on This PC, the
  same editor for defaults and connections, and one hotkey table behind the
  launcher, the on-screen hints and the docs. Deleting a PC can be undone.
  Keyboard access and contrast are better, and the launcher does no
  background work while a session is open. The classic Win32 hub is retired.
- **One Hyper password store.** Unticking Remember and Forget now do what
  they say; saved passwords carry over.
- **Android.** Rotating or attaching the keyboard cover keeps the connect
  form and a sign-in in progress; resolution is set in one place.
