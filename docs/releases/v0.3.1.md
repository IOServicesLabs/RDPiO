## rdpio 0.3.1

A steadier Hyper stream on a fast home network, and files copied on the host
reach the client.

- **A fast LAN streams at its speed.** On the host's own network the link is
  measured once a second, so a Wi-Fi radio's delay hiccups are no longer read
  as congestion. Between two Wi-Fi PCs the stream had sat at 0.5-4 Mbps,
  smeared whenever something moved. A late or lost keyframe no longer cuts
  the rate to the floor, and a remembered bad start is retuned 30 s in.
- **Copying files from the host works.** Files copied on the host (Explorer,
  any app) now paste on the client; each step a copy can stop at is logged.
- **The virtual monitor renders on the fastest GPU**, so laptops with two
  GPUs no longer end the stream at once.
- **Moving GPUs on a power change** (plugging in or unplugging a laptop) no
  longer drops the client to software rendering.
