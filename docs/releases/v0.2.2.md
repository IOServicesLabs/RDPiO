## rdpio 0.2.2

Sessions come back after the computer sleeps.

### Fixed

- **A session left open through sleep reconnects when the computer wakes.**
  Before, the window could sit on a frozen desktop, or give up with
  "Disconnected" before Wi-Fi was back. Now waking drops the dead connection
  and reconnects to the same session right away.
- **Reconnecting is more patient.** rdpio keeps trying for about two and a
  half minutes instead of about fifteen seconds, and a burst of network
  changes no longer uses up every retry at once.
- **"Disconnected" isn't final.** If rdpio runs out of retries, it tries
  again when the computer wakes or the network comes back. It still stays
  disconnected after a rejected password, or when the server ended the
  session on purpose (a sign-out, or another device taking it over).

### Downloads

- `rdpio-windows-x86_64.zip`: rdpio.exe, its signed manifest and the README.
- `rdpio.exe` and `rdpio.exe.update`: what updates download.
- `rdpio-linux-x86_64.tar.gz`: the Linux build (headless, see PORTING.md).
- `*.sha256`: checksums of the archives.
