## rdpio 0.2.1

A fix for updating from the launcher, and an easier install.

### Fixed

- **Update now / Restart to update in the launcher now installs the update.**
  In 0.2.0 the button did nothing and the banner kept coming back: the
  installer couldn't start from the launcher.

  If you're on 0.2.0, install 0.2.1 once by hand, using the one-liner below
  or the downloads on this page. From 0.2.1 on, the button works. Two update
  paths were never affected: a Hyper host updating itself, and a host
  passing updates to the devices that connect to it.

### New

- **One-line install** for Windows, per user, with no admin:

  ```powershell
  irm https://raw.githubusercontent.com/IOServicesLabs/RDPiO/main/install.ps1 | iex
  ```

  It installs to `%LOCALAPPDATA%\Programs\rdpio`, adds a Start menu shortcut
  and puts `rdpio` on your PATH, then opens the launcher. Run it again any
  time to reinstall.
- **Linux builds work again** (Hyper stays Windows-only).

### Downloads

- `rdpio-windows-x86_64.zip`: rdpio.exe, its signed manifest and the README.
- `rdpio.exe` and `rdpio.exe.update`: what updates download.
- `rdpio-linux-x86_64.tar.gz`: the Linux build (headless, see PORTING.md).
- `*.sha256`: checksums of the archives.
